模型說明文件

麻將對局模擬的數學推導

把目前程式中的三種計算拆開：單人自摸率、四家終局 EV，以及候選切牌的不確定性。本文描述的是模型估計，不是真人牌桌的精準機率。

符號單人模擬四家終局 共用亂數不確定性算例限制

1. 符號與樣本空間

34 種牌以 t = 0,…,33 表示，每種最多四張。令自己的手牌張數向量為 h，已知可見牌為 v，則未知池中第 t 種牌的數量為：

rₜ = 4 − hₜ − vₜ，且未知牌總數 R = Σₜ rₜ。

一次 trial 不是獨立地重抽每巡的牌，而是先對這個有限未知池做隨機排列；因此摸牌是不放回抽樣，並自然保持每種牌最多四張。

2. 單人自摸率模擬

對第 i 次 trial，定義首次聽牌巡目 Tᵢ，若模擬期內未聽則記為無限大；首次自摸巡目記為 Wᵢ。跑 N 次後，第 k 巡的累積估計為：

p̂tenpai(k) = (1/N) Σᵢ 𝟙[Tᵢ ≤ k]
p̂win(k) = (1/N) Σᵢ 𝟙[Wᵢ ≤ k]

每次摸到未胡的牌，模型先找令切牌後向聽數最小的候選；若有多張同分，再選擇下一摸能降低向聽數的剩餘實體張數最多者：

d* = arg maxd ∈ Dmin Σₜ rₜ · 𝟙[s(h − ed + eₜ) < s(h − ed)]

其中 s(·) 是向聽數，Dmin 是切後向聽數最低的牌集合，eₜ 表示增加一張 t。這就是有效牌（ukeire）數最大化。

範圍：這條曲線只回答「自己在第 k 巡以前聽牌／自摸的比例」，沒有對手先胡與放槍事件，因此不能直接當作完整對局勝率。

3. 四家終局 EV

對候選切牌 a，先抽樣隱藏世界 H（三家暗手）與後續亂數 U（牌牆順序、機率式榮和事件）。終局模擬器是一個映射：

Z(a,H,U) ∈ {自己自摸, 自己榮和, 對手榮和, 對手自摸, 流局}

家規結算函數把終局轉為四家點數變化 Δ = (Δ₀,Δ₁,Δ₂,Δ₃)，並滿足零和條件：

Σⱼ Δⱼ = 0。

若目前行動者座位為 q，單次樣本報酬就是 Xᵢ(a)=Δq。候選切牌的 net EV 是期望值的 Monte Carlo 樣本平均：

EV(a) = E[X(a)]
ÊV(a) = x̄(a) = (1/N) Σᵢ Xᵢ(a)

顯示用的進攻與風險欄位由同一批 signed payments 拆出：

AttackEV = (1/N) Σᵢ max(0,Xᵢ)
RiskEV = (1/N) Σᵢ max(0,−Xᵢ)
因此 x̄ = AttackEV − RiskEV。

榮和機率

每次切牌會對每位非切牌者計算危險分數 g，再以 self-play calibration 表得到 pron=C(g)。抽一個均勻亂數 u~Uniform(0,1)，當 u<pron 時產生該家的榮和 claim，再依家規解決一炮多響或優先序。

4. 為什麼所有候選共用亂數

比較切牌 a、b 時，模型讓兩者使用相同的 (Hᵢ,Uᵢ)，直接形成 paired difference：

Dᵢ = Xᵢ(a) − Xᵢ(b)
ÊV(a) − ÊV(b) = D̄。

差值估計的變異數為：

Var(D) = Var(X(a)) + Var(X(b)) − 2Cov(X(a),X(b))。

相似候選通常在同一牌牆下結果正相關，使 covariance 為正，因而降低差值雜訊。這不會使估計變成精確值，只是讓固定預算下的候選比較更穩定。

5. 標準誤與區間

對 N 個終局 payment，樣本變異數及平均值標準誤為：

s² = [1/(N−1)] Σᵢ (Xᵢ−x̄)²
SE(x̄) = s/√N。

常態近似的描述性 95% 區間是：

x̄ ± 1.959964 · SE(x̄)。

比較前兩名時應使用 paired samples 的 Dᵢ 計算區間，而不是把兩個候選的邊際區間分開看。如果差值區間跨過 0，模型應回報 unresolved：目前樣本不足以分辨高下。

Production 模式會先以小額 pilot 樣本估計候選的上下界，淘汰顯著落後者，再把完整預算集中在仍可能領先的候選；防守候選會另外保留。

6. 簡化算例

假設某候選跑 5 次，行動者的終局 payments 是 [+8, 0, −4, +2, −6]：

量推導結果
Net EV(8+0−4+2−6)/50
Attack EV(8+0+0+2+0)/52.0
Risk EV(0+0+4+0+6)/52.0
一致性Attack EV − Risk EV0 = Net EV

這也說明為什麼不能只看胡牌率：兩個候選即使胡牌率相同，胡牌價值、放槍頻率與放槍價值仍可能令 net EV 完全不同。

7. 推導成立的範圍

  • Monte Carlo 平均收斂的是目前模型定義的期望值；若隱藏手牌分布或 bot policy 與真人不同，增加樣本不會消除這種模型偏差。
  • RON lookup 由內建 bot self-play 校準，不代表真人牌譜。
  • Production EV 的未來狀態轉移未完整模擬吃、碰、槓、花牌、特殊牌型、過水與四家 best response。
  • 流局 payment 目前為 0，未加入聽牌／未聽罰付。
  • 95% 區間是抽樣不確定性的描述，不涵蓋規則選擇與 heuristic 假設造成的系統誤差。
